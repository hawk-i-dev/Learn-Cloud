## Day 1 Quiz

1. What is an Azure **subscription** primarily used for?  
   A. Storing files  
   B. Billing and access management  
   C. Creating websites  
   D. Training AI models  

2. What is a **resource group**?

   B. A container that organizes related Azure resources  
   C. A virtual machine

3. Which is an example of an Azure **resource**?  
   A. `rg-ai-learning-dev`  
   B. Central India  
   C. Azure Storage Account  
   D. Azure account  

4. Why is an Azure **region** important?  
   A. It determines where the service runs physically  
   B. It creates a password  
   C. It is only used to name resource groups  
   D. It deletes unused services  

5. For an AI chatbot project, which structure is best?

```text
A. Resource group → Subscription → Azure OpenAI
B. Subscription → Resource group → Azure OpenAI
C. Azure OpenAI → Region → Subscription
D. Region → Resource group → Azure account
```
